# ИИ-агент для ретрансляции обращений в поддержку

Решение кейса Intelligence CUP («Газпром нефть», 01.10–26.11).

Команда: Шарапова Елизавета (Санкт-Петербургский горный университет), Яковлев Алексей (СПбГЭТУ «ЛЭТИ»).

Агент собирает обращения пользователей цифровых продуктов, находит повторяющиеся проблемы и передаёт их продуктовым командам без дополнительной нагрузки на поддержку. Решение устроено как каскад: правила и простой классификатор отсекают операционные просьбы, Qwen 3.8 сжимает обращение до короткой причины «объект + проблема», похожие причины собираются в темы. Агент запускается только на сигналах, то есть на новых или растущих темах. Он проверяет бэклог, а затем создаёт карточку, дополняет существующую задачу или добавляет тему в дайджест. Всё работает во внутреннем контуре компании на Qwen 3.8, Qwen-ASR и Qwen-VL, без внешних API.

В базовом сценарии проект окупается за 3 года при вложениях до 14,4 млн ₽ (ставка дисконтирования 15%). MVP на пилоте стоит уложить в 7 млн ₽: тогда он окупается и в консервативном сценарии.
